AfriSovera OS is pre-alpha and has had **no security audit**. Do not rely on it to protect real data yet.

## Reporting a vulnerability

Please report security problems **privately**, using GitHub's private vulnerability reporting:
open the **Security** tab of this repository and choose **Report a vulnerability**.

Do not open a public issue, pull request or discussion for a security problem. We will acknowledge a
report as soon as we can and agree a disclosure date with you.
